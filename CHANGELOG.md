# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.2.1] - 2026-07-05

### Added

- Added a config option to change eggple hatch rates.

### Fixed

- Fixed the Warm and Fuzzy advancement instantly triggering.
- Fixed issues with the bouquet recipe advancement and A Seedy Soft Spot.
- Chapples no longer take fall damage.

## [2.2.0] - 2026-07-05

### Added

- Added Easy Anvils compat for Item Labels.
- Added additional Rubber blocks to round out the blockset.

## Changed

- Adjusted Turtle Raft rowing model.

### Fixed

- Fixed Turtle Rafts not properly being removed when broken.

## [2.1.4] - 2026-07-05

### Fixed

- Fixed worldgen deadlocks with certain biome mods.

## [2.1.3] - 2026-07-05

### Fixed

- Improve Redstone Wire Comparator mod compatibility.
- Performance improvements.

## [2.1.2] - 2026-07-04

### Fixed

- Fixed Iridescent Glass item models not being translucent on NeoForge.

## [2.1.1] - 2026-07-04

### Fixed

- Fixed issues with C2ME.
- Improved redstone wire performance.

## [2.1.0] - 2026-07-04

### Changed

- Tidal Helmet effect is now instantly removed when the helmet is unequipped.

### Fixed

- Fixed Iridescent Concrete and Iridescent Glazed Terracotta recipes.
- Fixed Terracotta Vase not correctly removing offsets.
- Fixed iridescent glass not recoloring beacon beams with Quark installed.
- Fixed bugs with certain sound files.
- Fixed player clipping into turtle raft.
- Fixed Iridescent Glass beacon beam not changing color with Quark.

## [2.0.1] - 2026-07-04

### Added

- Iridescent Glass now makes beacon beams rainbow.

## [2.0.0] - 2026-07-04

- Initial 1.21.1 release.
